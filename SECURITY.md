# 安全反馈 / Security reports

请勿在公开 issue 中粘贴 API 密钥、OAuth 令牌、签名私钥、完整设备地址、私人图片或对话。
如发现漏洞，请使用本仓库 Security → Report a vulnerability（私密报告）。若入口不可用，请仅公开提出需要私密联系方式，不附漏洞细节或任何凭据。误泄漏密钥请立即在服务商处撤销并轮换；删除 issue 或 Git 提交不能使旧密钥失效。

Do not put credentials, private signing keys, full device addresses, private images or conversations in public issues. Use Security → Report a vulnerability for confidential reports. If unavailable, request a private contact channel without posting exploit details or secrets. Revoke and rotate exposed credentials at the provider; deleting an issue or commit does not invalidate them.

This experimental preview has no security support SLA. Physical motion and AI/provider integrations still require device acceptance; see docs/acceptance.md.
